# Portfolio

Johann Layug's personal portfolio site: a single page that presents him to recruiters hiring for Forward Deployed Engineer and Agentic Engineering roles.

## Language

**Recruiter**:
The primary visitor the site is written for: a recruiter or hiring manager judging fit for FDE / Agentic Engineering roles in a few seconds.
_Avoid_: User, client, visitor (when meaning the target audience)

**Project**:
A piece of shipped work shown on the site, with a title, a one-line pitch, a longer description, tech tags, a screenshot (or, failing one, an illustrative terminal run), optionally a Demo video, and at least one public link (live or repo).
_Avoid_: Card, app, item

**Demo video**:
A screen recording of a Project in use, played from its screenshot on the site.
_Avoid_: Recording, clip, walkthrough

**Featured Project**:
A Project given visual priority over the others; at most one or two at a time.
_Avoid_: Highlight, pinned

**Project status**:
Whether a Project is _Shipped_ (usable by its intended user today) or _In progress_ (being built; shown with a visible badge).
_Avoid_: WIP, beta, done

**Pixel art**:
The site's retro identity: pixel portrait, pixel icons, pixel display font, stepped borders and hard offset shadows. Distinct from Win98 chrome.
_Avoid_: Retro (too vague)

**Win98 chrome**:
Imitation Windows 98 window furniture (title bars, `.exe` names, bevelled grey borders, status bars).
_Avoid_: Pixel art (when meaning this)
